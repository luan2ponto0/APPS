# Landpages

Repositório para landing pages de vendas.

## ShieldPoint — Consultoria de Segurança de Dados

Landing page de vendas para uma consultoria de segurança de dados online, com foco em:

- Diagnóstico de vulnerabilidades
- Conformidade com a LGPD
- Resposta a incidentes
- Segurança em nuvem
- Treinamento de equipes
- Monitoramento contínuo

### Estrutura

```
index.html   - estrutura da página (hero, serviços, planos, depoimentos, FAQ, contato)
styles.css   - estilos (tema dark, responsivo)
script.js    - menu mobile, FAQ e formulário de contato
```

### Como visualizar

Abra `index.html` diretamente no navegador, ou sirva a pasta com qualquer servidor estático:

```bash
npx serve .
```

### Deploy

Pronta para publicar via GitHub Pages: em *Settings → Pages*, selecione a branch `main` e a raiz do projeto.
